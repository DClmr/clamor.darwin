# Darwin Clamor — Virtual Assistant Portfolio

A responsive, single-page portfolio website for work applications. Built with plain HTML and CSS in a black-and-burgundy visual theme.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. GitHub will provide the published website URL in the Pages section.

## Add the supplied photographs

Create an `images` folder in the repository and upload these files using the exact filenames below:

| Filename | Image |
| --- | --- |
| `darwin-portrait.jpg` | Color portrait (black leather jacket and sunglasses) |
| `darwin-portrait-alt.jpg` | Monochrome portrait with glasses |
| `workspace.jpg` | Actual multi-monitor workspace |
| `internet-speed.png` | Internet speed-test screenshot |
| `macbook-air-m5.png` | MacBook Air M5 / display details screenshot |

The HTML references these paths. The photo files are not embedded in the website yet, so upload them before sharing the portfolio publicly.

## Content source

Career details, experience, skills, education, training and awards are summarized from Darwin Clamor's supplied resume. Equipment and speed-test figures are based on the screenshots supplied for this portfolio.
